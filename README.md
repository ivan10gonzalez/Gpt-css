# Universe Portal Prototype

Prototipo full-stack para pruebas internas: login único, redirección por rol, Master Root, plataforma de jugador, usuarios/agentes/cajeros, cargas y retiros de créditos virtuales, ledger, estadísticas y carga de imágenes.

Demo: `masteradmin` / `demo1234` · `jugador01` / `demo1234` · `agente01` / `demo1234` · `cajero01` / `demo1234`

Render: Root Directory vacío · Build `npm install` · Start `npm start`

**No procesa dinero real.** Los saldos y juegos son créditos virtuales de demostración. Para producción se requiere infraestructura persistente, seguridad, auditoría y cumplimiento normativo.
